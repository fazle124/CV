# Resume of Md. Fazle Rabbi (Android Application)

A professional Android Resume / Curriculum Vitae viewer and management application built with Kotlin and Jetpack Compose.

## Features

- **Document-Accurate Resume Layout**: Styled like a clean A4 resume sheet with serif headings, professional typography, contact badges (phone dialer, email composer, LinkedIn), profile photo, job experiences, educational qualifications, skills, personal info, and declaration with verified signature image.
- **Admin Dashboard**: Secure login for registered administrators to update header details, modify existing sections, add new sections, reorder sections with Move Up / Move Down, and delete sections.
- **Local Persistence & Remote Sync**: All changes persist locally across app sessions and automatically sync to the backend API (`https://cv-q3p4.onrender.com/api/cv-data`) when network connectivity is available.
- **PDF Export & Print**: Generate and share clean A4 PDFs or print directly using Android's native printing framework.
- **Protected Documents**: Verified records section to view certificates and national identity credentials.
